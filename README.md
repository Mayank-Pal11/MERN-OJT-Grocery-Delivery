# Grocery Delivery Web Application

This is an OJT (On-the-Job Training) project for a Grocery Delivery Web Application.

## Technology Stack

The project uses the MERN stack:
- **MongoDB**: NoSQL database (to be configured)
- **Express.js**: Backend web framework
- **React.js**: Frontend UI library
- **Node.js**: JavaScript runtime environment

## Project Structure

- `client/`: React + Vite frontend application.
- `server/`: Node + Express backend application.
